## 2. Tujuan Website

- Company Profile
- Media promosi layanan
- Meningkatkan kredibilitas perusahaan
- Menampilkan paket layanan
- Lead Generation
- Mempermudah calon pelanggan menghubungi via WhatsApp

---

## 3. Paket Layanan

Setiap paket berisi:
- Nama Paket
- Harga (95–100 SAR per pax)
- Deskripsi
- Itinerary
- Fasilitas
- Galeri Foto
- Jadwal Layanan (24 Jam)
- Lokasi: Jeddah, Mekkah, Madinah
- Syarat & Ketentuan

---

## 4. Sistem Booking

**Tidak ada sistem booking online.** Semua via WhatsApp.

**Alur:**
1. Pengunjung pilih paket
2. Klik "Booking Sekarang"
3. Terbuka WhatsApp Admin dengan pesan otomatis
4. Admin lanjutkan proses via WA
