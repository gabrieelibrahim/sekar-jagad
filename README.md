## Sections (all in index.html)
1. **Hero** — Headline, CTA, stats
2. **About** — Company profile
3. **Services** — Service list
4. **Packages** — Pricing & booking
5. **Gallery** — Photo/video documentation (horizontal scroll)
6. **Testimonials** — Client reviews
7. **FAQ** — Accordion Q&A
8. **CTA** — Call to action
9. **Contact** — Contact info + Google Maps

- Responsive (Desktop, Tablet, Mobile)
- WhatsApp Click-to-Chat integration
- Google Maps embed
